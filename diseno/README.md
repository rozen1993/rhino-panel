# Direcciones visuales
`direccion-a.html` presenta la propuesta operativa: densa, sobria y optimizada para lectura al sol.
`direccion-b.html` presenta la propuesta editorial: aireada, expresiva y con mayor presencia de marca.
Abre cualquiera de los dos archivos directamente en un navegador; no requieren servidor ni conexión.
Para compararlas en móvil, copia ambos archivos al teléfono o ábrelos con una ventana de 390 px.
