# Decisión operativa: modelo de tres roles

Este documento sustituye, para la implementación vigente, las decisiones anteriores que dependían de Coordinación, Supervisión, AUNOR, aprobaciones, observaciones o rechazos.

- Roles: Operario, Admin y Burson.
- Estados: Programada, En proceso y Entregada.
- Las actividades ordinarias se comunican fuera de la plataforma y las registra el operario.
- Burson registra sus encargos; el sistema los asigna al único operario especial activo.
- Admin observa toda la operación y gestiona cuentas, pero no ejecuta actividades.
- El Histórico se transforma en calendario anual interactivo y responsive.
- El material se entrega mediante enlace seguro de OneDrive/SharePoint; no existe Excel histórico independiente.
